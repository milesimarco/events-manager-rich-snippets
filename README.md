Extends Events Manager WordPress plugin with rich snippets preview (Google structured data).

## Features

- schema.org Event structured data (JSON-LD) on single event pages
- Upcoming events structured data on the Events Manager list and calendar pages
- Event timezone, all-day and cancelled events
- Physical, online and mixed locations
- Tickets as offers with price, currency and availability
- No settings needed

## Installation

Install it from the WordPress admin (**Plugins → Add New**, search for "Events Manager Rich Snippets") or download it from [WordPress.org](https://wordpress.org/plugins/events-manager-rich-snippets/).
